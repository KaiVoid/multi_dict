# multi_dict

Веб-клиент диктофонов **AIREC** и **DOWAY** по Web Bluetooth. Одностраничное приложение,
без сборки и установки — открывается прямо в браузере.

## Открыть

**Chrome / Edge** (десктоп или Android): <https://kaivoid.github.io/multi_dict/>

Web Bluetooth работает только в защищённом контексте (HTTPS), поэтому GitHub Pages
подходит. Safari и любой браузер на iOS не поддерживаются.

## Возможности

- Несколько устройств одновременно, переключение вкладками
- Список записей: скачивание, воспроизведение в браузере, удаление
- Управление записью: старт / пауза / стоп; у AIREC — прослушивание эфира в реальном времени
- Настройки устройства, синхронизация часов, форматирование (DOWAY)

## Локальный запуск

```bash
python3 -m http.server 8000
# затем открыть http://localhost:8000
```

`localhost` считается защищённым контекстом, так что Web Bluetooth работает.
